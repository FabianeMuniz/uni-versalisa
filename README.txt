UNI.VERSALISA — CATÁLOGO ESTÁTICO
=================================

COMO ABRIR
1. Extraia a pasta do ZIP.
2. Abra a pasta uni-versalisa no Visual Studio Code.
3. Abra index.html no navegador. Para facilitar, instale a extensão Live Server no VS Code,
   clique com o botão direito em index.html e selecione "Open with Live Server".

ANTES DE PUBLICAR
1. Abra script.js.
2. Troque WHATSAPP_NUMBER pelo seu número com código do país e DDD, apenas números.
3. Edite o array products: nome, descrição, preço, categoria e endereço da imagem.
4. Troque o link do Instagram em index.html.
5. Substitua as imagens de exemplo por fotos dos seus próprios produtos.

CATEGORIAS PERMITIDAS
- mandala-pintada
- mandala-tecida
- chaveiro
- brincos
- porta-treco

PUBLICAÇÃO
Você pode publicar os arquivos em um serviço de hospedagem estática que permita uso comercial,
como Cloudflare Pages, observando os limites do plano gratuito. Confira os termos atuais antes
de publicar. Não há backend nem checkout neste projeto.

OBSERVAÇÃO
As imagens remotas e os produtos/preços são apenas exemplos. Para um resultado profissional,
use fotos próprias otimizadas para web.
